# Provodkalar Kitobi

O‘zbek tilida (lotin yozuvida) buxgalteriya hisobi bo‘yicha amaliy darslik.
Asosiy urg‘u — **provodkalar**: har bir bob nazariya (MHXS/IFRS va BHMS/NSBU) →
provodkalar jadvali → yechilgan misol → mustaqil masala tartibida qurilgan.

**Fayl:** `index.html` — bitta mustaqil HTML sahifa (tashqi bog‘liqliksiz, faqat Google Fonts).

## Tarkibi

| Qism | Boblar |
|---|---|
| I. Nazariy asos | 1–5: balans tenglamasi, ikkiyoqlama yozuv, MHXS↔BHMS, hisobvaraqlar rejasi mantig‘i, aylanma-saldo qaydnomasi |
| II. Provodkalar | 6–18: asosiy vositalar, NMA, investitsiyalar va moliyaviy ijara, TMZ, tannarx, savdo, pul va valyuta, debitor/kreditorlar, mehnat haqi, soliqlar, kapital, moliyaviy natija, hisobot |
| III. Amaliyot | 19-bob: bir oylik to‘liq sikl; A ilova: hisobvaraqlar rejasi (qidiruv bilan); B ilova: provodkalar shpargalkasi; C ilova: xatolarni tuzatish (storno) |

## Manbalar va amal qilish muddati

- Hisobvaraqlar rejasi — **21-BHMS** «Xo‘jalik yurituvchi subyektlarda buxgalteriya hisobining
  hisobvaraqlar rejasi va uni qo‘llash bo‘yicha yo‘riqnoma» (AV 27.12.2024-y. 3593-son,
  01.01.2025-dan amalda; 24.09.2025-y. 3593-1-son o‘zgartirishlar bilan).
- Soliq stavkalari — **2026-yil** holatiga: QQS 12%, foyda solig‘i 15%, JShDS 12%,
  ijtimoiy soliq 12%, INPS 0,1%, aylanma solig‘i 4%, mol-mulk solig‘i 1,5%.

Kitob o‘quv maqsadida tayyorlangan va rasmiy hujjat o‘rnini bosmaydi.
