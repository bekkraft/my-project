Source: https://www.youtube.com/watch?v=ryhUGKzOFrA

Everything below is written in the language Suno understands (English).
Copy block 1 into **Style of Music**, block 2 into **Lyrics**.

## 1. STYLE (paste into "Style of Music")

```
Uzbek pop ballad, female lead vocal, warm and emotional, mid-tempo 4/4,
Central Asian estrada sound: doira frame drum, soft strings, oriental
melodic ornaments, modern pop synth and bass. Sung entirely in Uzbek
(Latin script), NOT English, Russian or Turkish.
Uzbek pronunciation rules for this song:
- "oy" = "oy" as in "boy", one short syllable.
- "o" = open short "o" as in British "hot", never "ow" (bo-QAR, so-hib-ja-MOL).
- "o'" = rounded deep "o" like Turkish "o" (to'-la, bo'-lib, o'r-may-man).
- "q" = deep "k" from the back of the throat (qal-bim, taq-dir, qil-may-man).
- "x" = "kh" as in German "Bach", never "ks" (o-xir).
- "g'" = throaty voiced "gh" like French "r" (g'a-za-lim).
- "h" = light breathy "h", always pronounced (hech, nigoh, sohib, bahor, mahliyo).
- "ch" = "ch" as in "chair" (chiroy, kechirgin); "sh" = "sh" (ishon, karashma).
- "j" = "dj" as in "jam" (jamol, jon).
- "r" = rolled Spanish/Russian "r", never English "r" (deraza, bahor, oxir).
- "l" = clear light "l" like Italian; "m", "n" = clean nasal sounds.
- "y" = "y" as in "yes" (yurmayman, mayli).
- Every vowel is sung fully and clearly, no reduction, no diphthongs.
Stress: on the LAST syllable of each word (se-NI, oy-lar-GA, qal-bim-NI),
EXCEPT negative verbs where stress is on the root before "-may":
BER-may-man, O'R-may-man, TER-may-man, YUR-may-man, QIL-may-man.
Syllables in CAPITALS in the lyrics are the stressed ones.
```

## 4. Quick fixes if something still sounds wrong

| Problem you hear                     | Add to Style / change in Lyrics                      |
|--------------------------------------|------------------------------------------------------|
| English "r" (soft, no roll)          | Style: `rolled Spanish r`                            |
| "o" sung as "ow"                     | Style: `short open o, no diphthongs`; Lyrics: `aw`   |
| "o'" read as "o + apostrophe"        | Lyrics: write `ō` or `oh` (tōla, bohlibman)          |
| "g'" read as "g"                     | Lyrics: write `gh` (ghazalim)                        |
| "x" read as "ks"                     | Lyrics: write `kh` (okhir)                           |
| "h" silent                           | Style: `every h is pronounced`                       |
| Stress on wrong syllable             | Keep CAPITALS; Style: `stress on capitalized syllables` |
| Vowels swallowed / mumbled           | Style: `every vowel fully pronounced, no reduction`  |
| Sounds Turkish or Arabic             | Style: `Uzbek accent, Tashkent dialect, not Turkish` |
