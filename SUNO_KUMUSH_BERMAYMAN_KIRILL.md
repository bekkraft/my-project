# Suno cheat sheet (Uzbek CYRILLIC): Kumush Razzoqova — «Мен сени ҳеч кимга бермайман»

Source: https://www.youtube.com/watch?v=ryhUGKzOFrA
Latin-script version: SUNO_KUMUSH_BERMAYMAN.md
Everything below is written in the language Suno understands (English),
the lyrics themselves are in Uzbek Cyrillic.
Copy block 1 into **Style of Music**, block 2 into **Lyrics**.

Note: with Cyrillic text Suno tends to default to a RUSSIAN accent
(reducing unstressed "о" to "а", softening consonants). The Style block
below fights that explicitly. If the accent still sounds Russian, use the
Latin-script version instead.

---

## 1. STYLE (paste into "Style of Music")

```
Uzbek pop ballad, female lead vocal, warm and emotional, mid-tempo 4/4,
Central Asian estrada sound: doira frame drum, soft strings, oriental
melodic ornaments, modern pop synth and bass. Sung entirely in UZBEK
written in Uzbek Cyrillic. This is NOT Russian: no Russian vowel
reduction, no palatalized (soft) consonants, unstressed "о" stays "о".
Uzbek Cyrillic letter guide for this song:
- "ў" = rounded deep "o" like Turkish "o" (тўла, бўлибман, ўрмайман).
- "о" = open short "o" as in British "hot", never "a", never "ow" (боқар, соҳибжамол).
- "ой" = "oy" as in "boy", one short syllable (ой, ойларга, чирой).
- "қ" = deep "k" from the back of the throat, deeper than "к" (қалбим, тақдирим, қилмайман).
- "к" = plain "k" (кечиргин, кимга).
- "ғ" = throaty voiced "gh" like French "r" (ғазалим).
- "ҳ" = light breathy "h", ALWAYS pronounced (ҳеч, нигоҳ, соҳиб, баҳор, маҳлиё, зинҳор).
- "х" = "kh" as in German "Bach" (охир).
- "ж" = "dj" as in "jam", NOT Russian "zh" (жамол, жон).
- "ч" = "ch" as in "chair"; "ш" = "sh" as in "ship".
- "й" = "y" as in "yes"; "ю" = "yoo" (юрмайман); "ё" = "yaw" (маҳлиё); "э" = "e" as in "bed" (энди, эй).
- "а" = open "ah"; "и" = "ee"; "у" = "oo"; "е" = "e" as in "bed".
- "р" = rolled Spanish/Russian "r"; "л" = clear light "l" like Italian, not dark;
  "м", "н" = clean nasal sounds; "нг" = one nasal sound as in "sing" (ойнинг, менинг).
- Every vowel is sung fully and clearly, no reduction, no diphthongs.
Stress: on the LAST syllable of each word (се-НИ, ой-лар-ГА, қал-бим-НИ),
EXCEPT negative verbs where stress is on the root before "-май":
БЕР-май-ман, ЎР-май-ман, ТЕР-май-ман, ЮР-май-ман, ҚИЛ-май-ман.
Syllables in CAPITALS in the lyrics are the stressed ones.
```

## 3. Cyrillic letter table (how to explain each letter to Suno)

| Cyrillic | Latin  | Where in the mouth                              | Tell Suno                                    |
|----------|--------|-------------------------------------------------|----------------------------------------------|
| а        | a      | open mouth, tongue flat and low                 | open "ah" as in "father"                     |
| о        | o      | open mouth, tongue back and low, lips barely rounded | short open "o" as in British "hot"; NEVER reduce to "a" like Russian |
| ў        | oʻ     | lips clearly rounded, tongue back and higher    | rounded deep "o" like Turkish "o"            |
| у        | u      | lips in a tube, tongue high back                | "oo" as in "moon"                            |
| и        | i      | lips spread, tongue high front                  | "ee" as in "see"                             |
| э / е    | e      | half-open mouth, tongue mid-front               | "e" as in "bed"                              |
| ё        | yo     | "й" + "о"                                       | "yaw" (маҳлиё = mah-lee-YAW)                 |
| ю        | yu     | "й" + "у"                                       | "yoo" (юрмайман = YOOR-my-mahn)              |
| й        | y      | tongue high front, gliding                      | "y" as in "yes"; "ой" = "oy" as in "boy"     |
| р        | r      | tongue tip taps/trills behind upper teeth       | rolled "r" like Spanish, never English "r"   |
| л        | l      | tongue tip at upper teeth, not pulled back      | clear light "l" like Italian                 |
| м        | m      | lips closed, sound through the nose             | clean nasal "m"                              |
| н        | n      | tongue tip at upper teeth, through the nose     | clean "n"; before к/г sounds like "ng"       |
| нг       | ng     | back of tongue at soft palate, one sound        | one nasal sound as in "sing"                 |
| к        | k      | back of tongue at soft palate                   | plain "k" as in "sky"                        |
| қ        | q      | root of tongue at the uvula, deeper than к      | deep "k" from the back of the throat         |
| г        | g      | like к, voiced                                  | hard "g" as in "go"                          |
| ғ        | gʻ     | root of tongue at the uvula, voiced friction    | throaty voiced "gh" like French "r"          |
| х        | x      | same place as ғ, voiceless                      | "kh" as in German "Bach", never "ks"         |
| ҳ        | h      | light breath from the larynx                    | light breathy "h", always pronounced         |
| ж        | j      | front of tongue at the hard palate              | "dj" as in "jam" (NOT Russian "zh") in native words; "zh" only in loanwords like журнал |
| ш        | sh     | tongue at hard palate, lips slightly forward    | "sh" as in "ship"                            |
| ч        | ch     | stop + "ш"                                      | "ch" as in "chair"                           |
| с / з    | s / z  | tongue tip at teeth, narrow gap                 | "s" as in "sun", "z" as in "zoo"             |
| т / д    | t / d  | tongue tip at upper teeth                       | dental "t" and "d"                           |
| б / п    | b / p  | lips                                            | "b" as in "boy", "p" as in "pen"             |
| в / ф    | v / f  | lips, narrow gap                                | "v" as in "van", "f" as in "fan"             |
| ъ        | ʼ      | short closure in the larynx                     | short glottal pause / lengthened vowel (аъло, санъат) |

## 5. Quick fixes if something still sounds wrong

| Problem you hear                        | Add to Style / change in Lyrics                          |
|-----------------------------------------|----------------------------------------------------------|
| Sounds Russian (о → а, soft consonants) | Style: `Uzbek, not Russian; unstressed о stays о; no soft consonants` |
| English "r"                             | Style: `rolled Spanish r`                                |
| "о" sung as "ow"                        | Style: `short open o, no diphthongs`; Lyrics: `aw`       |
| "ў" sung like Russian "у" or "о"        | Lyrics: write `ō` or Latin `oh` (тōла, бōлибман)         |
| "ғ" sung as plain "г"                   | Lyrics: write Latin `gh` (ghазалим)                      |
| "х" too weak or sung as "ks"            | Lyrics: write `kh`                                       |
| "ҳ" silent                              | Style: `every ҳ is pronounced as h`                      |
| "ж" sung as Russian "zh"                | Style: `ж = dj as in jam`; Lyrics: `дж` (джон, джамол)   |
| Stress on wrong syllable                | Keep CAPITALS; Style: `stress on capitalized syllables`  |
| Vowels swallowed                        | Style: `every vowel fully pronounced, no reduction`      |
