# ПАКЕТ-МАНИФЕСТ «СТОРИБОРД → ФИЛЬМ»

Раздел 5.6 мастер-промпта. Жёсткая связь между панелями сториборда и
видео-промптами через сквозной ID.

## КАК ЭТИМ ПОЛЬЗОВАТЬСЯ

1. Генерируешь панель по промпту из файла раскадровки
2. **Сохраняешь картинку под именем ID:** `S12a.png`, `S58c.png` и т.д.
3. При генерации видео находишь по ID: панель-картинку + промпт из `VIDEO-PROMPTS.md`
4. Отправляешь в генератор ВЕСЬ пакет: картинка как start frame + промпт с тем же ID

## ПРАВИЛО «ОСНОВА = ПАНЕЛЬ»

Панель — это БАЗА сцены. Композиция, ракурс, объекты, персонаж, свет, цвет
и одежда сохраняются в видео без изменений. Промпт описывает только движение.
Менять что-либо относительно панели — запрещено без согласования.

## ВСЕГО: 256 панелей · 124 видео-сцены

Колонка «Видео» отмечает панели, которые служат стартовым кадром для
видео-промпта. Остальные панели — промежуточные фазы движения: они нужны,
чтобы выверить действие, и в генерацию видео как start frame не идут.
