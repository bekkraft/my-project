## ГЛАВНЫЕ ПРАВИЛА

**Консистентность.** Токены `[SHOHRUH]`, `[TEMUR]`, `[CAR]` и т.д. разворачиваются
ДОСЛОВНО одинаково во всех панелях. Это и есть механизм, который не даёт
лицу и машине плыть от кадра к кадру.

**Машину описывать кузовом, не названием.** Генератор не знает «Nexia R3» и
подставляет случайный старый седан. Работает только описание кузова Aveo T250.

**Основа = панель.** Видео-промпт описывает ТОЛЬКО движение. Композиция,
ракурс, свет, цвет и одежда приходят со стартовым кадром и не меняются.

**Имя файла = ID.** `S12a.png`, не `image_final_v2.png`. На этом держится
весь манифест.
