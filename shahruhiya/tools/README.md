# ИНСТРУМЕНТЫ

## label_panels.py — разметка панелей номерами

### Зачем
Чтобы отправить ИИ сториборд-лист и промпты со сценами, и ИИ нашёл нужную
панель по номеру.

### Почему номер нельзя нарисовать генератором
1. **Генераторы изображений не умеют писать текст.** «S12a» превратится в
   «5I2q» или «SI2a», и в каждой панели по-своему. Номер, который нельзя
   прочитать, хуже, чем никакого.
2. **Номер попадёт в видео.** Панель идёт в генератор видео как СТАРТОВЫЙ
   КАДР. Всё, что на ней нарисовано, окажется в первом кадре ролика —
   включая номер, и он ещё поедет вместе с камерой.

Поэтому номер дорисовывается ПРОГРАММНО после генерации: один шрифт,
одно положение, полоса ПОД кадром, композиция не тронута.

### Две версии каждой панели

| Файл | Что | Куда |
|---|---|---|
| `S12a.png` | чистая панель | → в видео как start frame |
| `labeled/S12a_L.png` | та же + полоса с номером | → в сториборд-лист |

**В генератор видео всегда идёт ЧИСТАЯ версия.** Размеченная — только для
чтения человеком и для листа, который смотрит ИИ при разборе сцен.

### Установка
```
pip install Pillow
```

### Использование

Сложи сгенерированные панели в папку, назвав файлы по ID:
```
panels/
  S12a.png
  S12b.png
  S13a.png
```
(если назвал без префикса — `12a.png` — скрипт сам доклеит `S`)

**Разметить номерами:**
```
python3 label_panels.py label ./panels
```
→ `panels/labeled/S12a_L.png` и т.д. Чистые оригиналы не тронуты.

**Собрать контактные листы:**
```
python3 label_panels.py sheet ./panels/labeled --cols 4 --rows 3
```
→ `panels/sheets/sheet_01_S12a-S15b.png` по 12 панелей на лист

**И то и другое сразу:**
```
python3 label_panels.py all ./panels --cols 4 --rows 3
```

### Настройка вида
В начале скрипта:
```python
BAR_RATIO  = 0.075        # высота полосы, доля от высоты панели
BAR_COLOR  = (16,16,18)   # цвет полосы
TEXT_COLOR = (255,255,255)
```

## КАК ЭТО ВСТРАИВАЕТСЯ В ПРОЦЕСС

```
1. Генерируешь панель по промпту из STORYBOARD-0X.md
2. Сохраняешь как S12a.png          ← чистая
3. python3 label_panels.py all ./panels
4. Листы sheets/ — смотришь сам, показываешь мне, отправляешь ИИ
5. Для видео берёшь ЧИСТУЮ S12a.png + промпт [SCENE S12a]
```

**Ключевое:** размеченная версия нужна для навигации и обсуждения.
Чистая — для производства. Никогда не подставляй `_L` версию как start frame.
