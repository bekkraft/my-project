# Подпись для Outlook — Бекзод Азизов

- `signature.html` — готовая подпись. **Логотип уже вшит в файл**, ничего докладывать не нужно.
- `logo-agmk-vertical.png` — логотип: знак сверху, название комбината тремя строками под ним (используется в подписи).
- `logo-agmk-short.png` — тот же знак с короткой подписью «АГМК» под ним.
- `logo-agmk-mark.svg` — только знак, вектор (для печати/крупных размеров).
- `embed-logo.py` — скрипт для замены логотипа на другой файл.

## Как поставить в Outlook

1. Откройте `signature.html` двойным кликом — он откроется в браузере (Edge/Chrome).
2. Выделите подпись целиком (от «С уважением,» до адреса почты) и нажмите **Ctrl+C**.
3. Outlook → **Файл → Параметры → Почта → Подписи…** → **Создать**, задайте имя (например, «Основная»).
4. Кликните в поле редактирования подписи и нажмите **Ctrl+V**.
5. Справа вверху выберите: «Новые сообщения» и «Ответ/пересылка».
6. **ОК**.

При копировании через браузер Outlook сам вкладывает логотип в письмо — получателям он виден, ничего скачивать им не нужно.

### Outlook в браузере (OWA)
Настройки (шестерёнка) → **Почта → Создание и ответ → Подпись электронной почты** → **Ctrl+V** → **Сохранить**.

## Про логотип

Логотип воссоздан векторно по образцу (золотая капля с кольцом и внутренней каплей + название под знаком).
Если есть официальный файл логотипа от отдела маркетинга — лучше поставить его:

```
python3 embed-logo.py путь/к/официальный-логотип.png
```

Скрипт вшивает картинку прямо в `signature.html`; после этого повторите шаги 1–6.
Второй необязательный аргумент — ширина логотипа в подписи в пикселях (по умолчанию 160).

## Важные мелочи

- Не вставляйте логотип в Outlook через «Вставить рисунок → по ссылке»: он должен быть вложен в письмо, иначе у получателя будет пустой квадрат.
- Копируйте подпись именно из браузера. Если положить `signature.html` напрямую в `%APPDATA%\Microsoft\Signatures`, Outlook для Windows не покажет вшитую картинку.
- Телефон и почта кликабельные (`tel:` и `mailto:`), цвет — как у обычного текста, без синего подчёркивания.
- Чтобы поменять текст, должность или контакты — правьте `signature.html` и повторите шаги 1–6.
