# Подпись для Outlook — Бекзод Азизов

Файлы:
- `signature.html` — сама подпись (HTML, таблица, совместима с Outlook для Windows/Mac/Web).
- `logo.png` — сюда положите файл логотипа АГМК (тот, что во вложении). Имя файла должно быть именно `logo.png`.

## Шаг 1. Положить логотип

Сохраните картинку логотипа рядом с `signature.html` под именем `logo.png`.
Рекомендуемый размер исходника — ширина 300–400 px (в подписи он отображается на 112 px, запас нужен для экранов Retina).

## Шаг 2. Вставить подпись в Outlook (самый надёжный способ)

1. Откройте `signature.html` двойным кликом — он откроется в браузере (Edge/Chrome).
2. Выделите подпись мышью целиком (от «С уважением,» до адреса почты) и нажмите **Ctrl+C**.
3. Outlook → **Файл → Параметры → Почта → Подписи…** → **Создать**, задайте имя (например, «Основная»).
4. Кликните в поле редактирования подписи и нажмите **Ctrl+V**.
5. Справа вверху выберите, для каких сообщений её использовать: «Новые сообщения» и «Ответ/пересылка».
6. **ОК**.

При таком способе Outlook сам вкладывает логотип в письмо — получателям он виден, ничего докачивать не нужно.

### Вариант для Outlook в браузере (OWA)
Настройки (шестерёнка) → **Почта → Создание и ответ → Подпись электронной почты** → вставить скопированное (Ctrl+V) → **Сохранить**.

## Важные мелочи

- Не вставляйте подпись через «Вставить рисунок → по ссылке» — логотип должен быть вложен в письмо, иначе у получателя будет пустой квадрат.
- Если нужно поменять текст/телефон — правьте `signature.html` и повторите Шаг 2.
- Телефон и почта сделаны кликабельными (`tel:` и `mailto:`), цвет ссылок — как у обычного текста, без синего подчёркивания.
